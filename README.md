# Linux & Ubuntu Command Reference

**Version 1.0 · August 2026**  
Created by Tanner Gay

A practical, screen-friendly command reference for Linux and Ubuntu.  
Built for people who actually use the terminal — not for textbooks.

Two editions are included:

- **Dark** — for screen use
- **Light** — ink-saver / printer edition

---

## What’s inside

- 90+ carefully selected commands
- Clear difficulty badges: `ESSENTIAL` · `INTERMEDIATE` · `POWER USER` · `DANGER`
- Consistent card layout (purpose → syntax → examples → tip)
- Safety notes on destructive operations
- Network troubleshooting ladder
- Permission decoder
- Quick-reference tables (permissions, signals, globs, redirections, keyboard shortcuts)
- Alphabetical index with page numbers
- Full section bookmarks

The focus is on the commands you actually reach for, explained briefly and accurately.

## Design principles

- **Scannable** — every card follows the same structure
- **Honest** — DANGER badges and stronger warnings on irreversible actions
- **Practical** — examples show real outcomes, not just flags
- **Complete enough** — covers daily work without becoming an encyclopedia

---

## How to use

1. Open the dark edition on screen or the light edition for printing.
2. Use `Ctrl+F` to jump to any command.
3. Use the PDF sidebar bookmarks to move between sections.
4. Check the alphabetical index on the last page for page numbers.
